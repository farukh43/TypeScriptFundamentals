# TypeScript Fundamentals

This project contains practical TypeScript examples and exercises arranged as a day-by-day learning path. The source files are in [TypeScriptFundamentals](TypeScriptFundamentals/).

## Course Outline

- **Day 2:** Variables with `var`, `let`, and `const`, including scope, reassignment, and hoisting.
- **Day 3:** Primitive data types, type annotations, type inference, union types, and return types.
- **Day 4:** Arithmetic, assignment, comparison, equality, and logical operators.
- **Day 5:** Conditional statements using `if`, `else if`, `else`, nested conditions, and `switch`.
- **Day 6:** `while`, `do...while`, and `for` loops, including `break` and `continue`.
- **Day 7:** Named functions and arrow functions with parameters, return values, optional parameters, default values, and rest parameters.
- **Day 8:** Callback functions and function overloading.
- **Day 9:** Arrays, array iteration, array parameters, tuple types, and arrays of tuples.
- **Day 10:** Common array methods such as `push`, `pop`, `slice`, `splice`, `indexOf`, `includes`, and `join`.
- **Day 11:** Advanced array methods: `forEach`, `map`, `filter`, `reduce`, `some`, and `every`.
- **Day 12:** String templates, indexing, common string methods, splitting, trimming, concatenation, and immutability.
- **Day 13:** Objects, inline object types, type aliases, intersection types, and classes.
- **Day 14:** Constructor and method overloading with a `Calculator` class, plus read-only, optional, and static class members with `Student`.
- **Day 15:** Reinforces constructor and method overloading and class members through the same `Calculator` and `Student` examples.

See the [course-specific README](TypeScriptFundamentals/README.md) for the file-by-file guide.
