# TypeScript Fundamentals

This folder contains runnable examples and practice exercises for learning TypeScript step by step. Most files can be run with `tsx <filename>`.

## Daily Lessons

### Day 2: Variables

`day02-variables.ts` introduces `var`, `let`, and `const`, with examples of scope, declaration, reassignment, redeclaration, and hoisting.

### Day 3: Data Types

`day03-data-types.ts` covers primitive types, annotations, type inference, `any`, union types, `null`, `undefined`, and function return types.

### Day 4: Operators

`day04-operators.ts` demonstrates arithmetic, assignment, relational, equality, strict equality, and logical operators.

### Day 5: Conditional Statements

`day05-conditional-statements.ts` explains `if`, `else if`, `else`, nested conditions, and `switch` statements.

`day05-conditional-statements-assignments.ts` provides practice problems using those conditional structures.

### Day 6: Looping Statements

`day06-looping-statements.ts` introduces `while`, `do...while`, and `for` loops.

`day06-looping-statements-assignments.ts` applies loops to number problems and demonstrates `break` and `continue`.

### Day 7: Functions

`day07-named-functions.ts` covers named functions, parameters, return types, optional parameters, default parameters, and rest parameters.

`day07-arrow-functions.ts` covers arrow functions, implicit returns, and the same parameter patterns in a shorter syntax.

### Day 8: Callbacks and Overloading

`day08-callback-functions.ts` shows how to pass functions as arguments and execute callbacks.

`day08-overloaded-functions.ts` demonstrates multiple function signatures with one compatible implementation.

### Day 9: Arrays and Tuples

`day09-Arrays.ts` introduces typed arrays, generic array syntax, iteration, and functions that accept or return arrays.

`day09-Tuple.ts` covers fixed-length tuples, tuples with different element types, iteration, and arrays of tuples.

### Day 10: Array Methods

`day10-ArrayMethods.ts` demonstrates methods that add, remove, combine, search, copy, and convert array values, including `push`, `pop`, `slice`, `splice`, `indexOf`, `includes`, and `join`.

### Day 11: Advanced Array Methods

`day11-AdvancedArrayMethods.ts` explains `forEach`, `map`, `filter`, `reduce`, `some`, and `every` using callback functions.

### Day 12: Strings

`day12-Strings.ts` covers string literals, template strings, indexing, searching, replacement, splitting, trimming, concatenation, and string immutability.

### Day 13: Objects

`day13-Objects.ts` demonstrates object properties and methods, inline object types, type aliases, intersection types, and classes.

### Day 14: Overloading and Classes

`day14-Overloading.ts` demonstrates constructor and method overloading with a `Calculator` class.

`day14-Student.ts` demonstrates classes with read-only properties, optional properties, static properties, and static methods.

### Day 15: Overloading and Classes Practice

`day15-Overloading.ts` reinforces constructor and method overloading with the `Calculator` class.

`day15-Student.ts` reinforces read-only, optional, and static class members with the `Student` class.
